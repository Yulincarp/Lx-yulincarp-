# Lx-yulincarp

一个 Minecraft Java 版启动器，专注于**版本覆盖广、启动稳定**。

## 支持版本

**从远古版本到最新版，全线覆盖：**

| 版本区间 | 说明 |
|---|---|
| Alpha / Beta 远古版 | 支持启动 |
| 1.x 全系列 | 1.0 ～ 1.21 各正式版 |
| 26.x 新版 | 已支持到 **26.4** |

> 旧版本依赖的运行环境会自动补齐，无需手动装 Java。

## 下载

| 文件 | 说明 |
|---|---|
| `Lx-yulin-carp-1.4.0-Setup.exe` | Windows 安装程序（64 位），约 63 MB |

在仓库文件列表中点击该文件 → 右上角 **Download** 即可下载。

## 安装

1. 下载 `Lx-yulin-carp-1.4.0-Setup.exe`
2. 双击运行，按提示完成安装
3. 如出现"Windows 已保护你的电脑"，点 **更多信息** → **仍要运行**
4. 启动器首次运行会自动准备所需组件

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 内存 | 4 GB 以上（跑新版本建议 8 GB+） |
| 磁盘 | 约 200 MB（不含游戏本体与存档） |

## 常见问题

**Q：启动时提示缺少 Java？**
A：启动器会自动下载对应版本所需的 Java 运行环境，保持网络畅通即可。

**Q：杀毒软件报毒？**
A：安装包未做数字签名，部分杀软会误报。可加入信任列表，或核对文件大小是否为 63.12 MB。

**Q：支持正版登录吗？**
A：见启动器内账号设置。
