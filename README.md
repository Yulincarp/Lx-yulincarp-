# Lx-yulincarp

自用工具 / 安装包发布仓库。

## 下载

| 文件 | 说明 |
|---|---|
| `Lx-yulin-carp-1.4.0-Setup.exe` | Windows 安装程序（64 位） |

## 安装

1. 下载上面的 `Setup.exe`
2. 双击运行，按提示安装
3. 首次启动如提示"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」

## 系统要求

- Windows 10 / 11（64 位）
- 约 200 MB 可用磁盘空间

## 版本

- **v1.4.0** — 当前版本
